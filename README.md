# Beckatex

Base inicial de Next.js con App Router, TypeScript y Tailwind CSS.

## Inicio
Requiere Node.js 20.9 o superior y npm.

```powershell
npm ci
npm run dev
```

Abrir http://localhost:3000.

## Comprobaciones
```powershell
npm run lint
npm run typecheck
npm run build
```

Para ejecutar la compilación: npm run start.

## Continuar con Claude Code
Abrir la carpeta del proyecto en Claude Code. CLAUDE.md contiene el contexto y las convenciones.
Las skills están en .claude/skills y se pueden invocar como:
- /becka-next
- /becka-design
- /becka-content
- /becka-check

Ejemplo: "Usa /becka-design para ajustar la portada con mi logo y colores."

## Estado
Portada inicial adaptable en español con ilustración CSS. Identidad y textos provisionales.
Sin catálogo real, formularios, pagos ni servicios externos.
Faltan logo, productos, fotografías, contacto y definición del objetivo comercial.
No necesita variables de entorno para arrancar.
