description: Diseñar o modificar la interfaz de Beckatex, incluyendo estilos, componentes visuales, adaptación móvil y accesibilidad.
---

La dirección inicial es editorial: fondo marfil, tonos terracota y olivo, titulares serif y texto sans. Es provisional hasta recibir identidad oficial.
Reutilizar las variables de globals.css. Mantener una jerarquía clara y evitar multiplicar variantes sin necesidad.
Las telas de la portada son una ilustración CSS, no fotografías de productos reales. No presentarlas como mercancía.
Diseñar para que no haya desbordamiento horizontal a 360, 768 y 1440 px, con texto legible y enlaces utilizables, pero solo comprobarlo en un navegador si el usuario pide una revisión visual.
Conservar navegación por teclado, foco visible, enlace para saltar al contenido y orden lógico de encabezados.
Para controles nuevos, usar elementos semánticos y etiquetas accesibles. No transmitir estados solo con color.
Respetar prefers-reduced-motion y verificar contraste cuando se cambie la paleta.
No hacer revisiones visuales (navegador, capturas, anchos de pantalla ni servidores de prueba) salvo que el usuario las pida de forma expresa. Si las pide, documentar lo observado, cerrar los servidores al terminar y no afirmar revisiones que no se hicieron.
